### API集成
[Source: Story 1.2和1.3实现结果]
相关API端点：
- `POST /api/admin/auth/login` - 返回2FA状态和临时令牌
- `POST /api/admin/auth/verify-2fa` - 验证TOTP或备用码，返回最终令牌

API响应格式：
```typescript
// 登录响应(需要2FA)
{
  requiresTwoFactor: true,
  tempToken: string,
  message: string
}

// 2FA验证响应
{
  token: string,
  user: UserInfo,
  message: string
}
```

### 状态管理规格
[Source: architecture.md#状态管理]
认证Store需要支持的状态：
```typescript
interface AuthState {
  isAuthenticated: boolean
  user: User | null
  token: string | null
  tempToken: string | null  // 2FA临时令牌
  requiresTwoFactor: boolean
  loading: boolean
}
```
