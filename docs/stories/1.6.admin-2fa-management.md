### API集成规格
[Source: 现有用户管理API分析]
需要扩展的API端点：
- `GET /api/admin/user/list` - 扩展返回2FA状态字段
- `POST /api/admin/user/reset-2fa` - 重置用户2FA设置
- `GET /api/admin/log/2fa-operations` - 查询2FA相关操作日志
- `GET /api/admin/statistics/2fa-usage` - 获取2FA使用统计

API响应格式扩展：
```typescript
// 用户列表响应扩展
interface AdminUser {
  id: number
  username: string
  email: string
  // 新增2FA字段
  twoFactorEnabled: boolean
  twoFactorVerifiedAt?: string
  twoFactorBackupCodesCount?: number
}

// 2FA统计响应
interface TwoFactorStats {
  totalUsers: number
  enabledUsers: number
  enabledRate: string
  dailyVerifications: number[]
  topVerificationHours: {hour: number, count: number}[]
}
```

[Source: 现有权限系统分析]
需要新增的权限点：

- `/admin/2fa/reset` - 重置2FA权限
- `/admin/2fa/logs` - 查看2FA日志权限
- `/admin/2fa/statistics` - 查看统计权限

权限控制集成：
```typescript
// 在用户列表组件中
v-if="hasPermission(['/admin/2fa/view'])"
// 在重置按钮中
auth: ['/admin/2fa/reset']
```
