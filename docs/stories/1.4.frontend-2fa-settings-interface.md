# Story 1.4: 前端2FA设置界面

## Status
Done

## Story
**As a** 用户，
**I want** 有一个直观易用的界面来设置和管理我的双因素认证，
**so that** 我能够轻松地增强账户安全性。

## Acceptance Criteria
1. 在用户设置页面添加2FA管理区域
2. 实现2FA启用向导，包括QR码显示和验证步骤
3. 创建备用码显示和管理界面
4. 实现2FA禁用功能，需要密码确认
5. 添加2FA状态指示和相关说明文档
6. 确保所有界面响应式设计，支持移动端

- 事件命名使用动词形式 (enable, disable, verify)

### API 集成信息

**2FA 相关 API 端点** [Source: Story 1.2 完成记录]:
- `GET /api/admin/auth/two-factor/status` - 查询2FA状态
- `POST /api/admin/auth/two-factor/enable` - 启用2FA
- `POST /api/admin/auth/two-factor/verify-setup` - 验证2FA设置
- `POST /api/admin/auth/two-factor/disable` - 禁用2FA
- `GET /api/admin/auth/two-factor/backup-codes` - 获取备用码
- `POST /api/admin/auth/two-factor/regenerate-backup-codes` - 重新生成备用码
- `GET /api/admin/auth/two-factor/qr-code` - 获取QR码数据

### 错误处理和用户反馈标准化

**错误分类和处理** [Source: docs/2fa-enhancement-requirements-brief.md#2.9]:

1. **用户输入错误**:
   - 错误类型: 验证码格式错误
   - 错误代码: 2FA_INVALID_FORMAT
   - 用户提示: "验证码应为6位数字，请检查后重新输入"
   - 技术日志: "Invalid TOTP format: {input}"

2. **验证失败错误**:
   - 错误类型: TOTP验证失败
   - 错误代码: 2FA_VERIFICATION_FAILED
   - 用户提示: "验证码不正确，请确认时间同步后重试"
   - 技术日志: "TOTP verification failed for user {userId}"

3. **系统错误**:
   - 错误类型: QR码生成失败
   - 错误代码: 2FA_QR_GENERATION_ERROR
   - 用户提示: "系统暂时无法生成二维码，请稍后重试"
   - 技术日志: "QR code generation failed: {error}"

4. **网络错误**:
   - 错误类型: 网络请求超时
   - 错误代码: 2FA_NETWORK_TIMEOUT
   - 用户提示: "网络连接超时，请检查网络后重试"
   - 技术日志: "API request timeout: {endpoint}"

**反馈机制**:

1. **即时反馈**:
   - 表单验证: 实时显示错误信息
   - 操作反馈: Loading状态 + 成功/失败提示
   - 进度指示: 多步骤流程的进度条

2. **持久化反馈**:
   - 成功操作: 绿色Toast提示，3秒自动消失
   - 错误信息: 红色Toast提示，需用户手动关闭
   - 警告信息: 黄色Toast提示，5秒自动消失

3. **帮助引导**:
   - 错误信息附带解决建议
   - 提供相关帮助文档链接
   - 严重错误提供客服联系方式
