# AniX 漫画阅读应用功能设计文档

## 1. 功能模块概述

本文档详细描述 AniX 漫画阅读应用各功能模块的设计规范、交互逻辑和实现细节，为开发团队提供详细的功能实现指导。

## 2. 用户系统功能设计

### 2.1 用户注册功能

**功能描述**：用户通过邮箱或手机号注册账户

**输入参数**：

* 用户名（3-20个字符，支持中英文数字下划线）

* 邮箱地址（符合邮箱格式规范）

* 密码（8-20位，包含字母数字）

* 确认密码（与密码一致）

* 验证码（图形验证码或短信验证码）

**业务逻辑**：

1. 前端表单验证（实时验证用户名、邮箱格式）
2. 检查用户名和邮箱唯一性
3. 密码强度验证和加密存储
4. 发送邮箱验证链接
5. 创建用户记录并返回注册成功信息

**异常处理**：

* 用户名已存在：提示选择其他用户名

* 邮箱已注册：提示直接登录或找回密码

* 验证码错误：刷新验证码重新输入

* 网络异常：显示友好错误提示

### 2.2 用户登录功能

**功能描述**：用户通过用户名/邮箱和密码登录系统

**输入参数**：

* 用户名或邮箱

* 密码

* 记住登录状态（可选）

* 图形验证码（登录失败3次后显示）

**业务逻辑**：

1. 验证用户输入格式
2. 查询用户信息并验证密码
3. 生成 JWT Token 并设置过期时间
4. 记录登录日志和设备信息
5. 返回用户信息和访问令牌

**安全机制**：

* 密码错误次数限制（5次锁定30分钟）

* JWT Token 有效期管理

* 异地登录提醒

* 登录设备记录

### 2.3 个人中心功能

**功能模块**：

* 个人信息管理

* 头像上传和修改

* 密码修改

* 阅读偏好设置
